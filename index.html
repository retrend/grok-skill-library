For AI agents

Point a bot at llms.txt. It explains the library and lists every skill.

  • index.json: every skill's id, description, tags and link, without the full text.
  • skills/<id>.md: one skill as raw Markdown.
  • llms-full.txt: all skills in one file.
  • library.json: the Library catalogue (outside skills, agents, plugins and more found by Library Scout).

WebMCP tools. In a browser with WebMCP (navigator.modelContext), this page registers read-only tools an agent can call: search_skills, get_skill, list_skills, search_library and get_library_entry. They run in the page and only read this site's files. Tool list and inputs: webmcp.json.
