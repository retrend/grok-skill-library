# Comedy Morgue cut check

Goal: every cut is right before it goes out or before Steven watches it. Recuts are a full round of work, so the checks come first.

## 1. Cut Brief (before the script)

Save to the episode folder as cut-brief.md. One screen:

- Thesis in one sentence.
- Brand: Comedy Morgue or Comedy Ombudsman, and why.
- Runtime target: 16 to 22 minutes.
- The five argument lines from the Comedy Morgue script method skill.
- Format (Versus, Saga update, Autopsy) and the story score from /workspace/youtube-research/comedy-morgue/METHOD.md.
- First spoken line and first frame.
- The payoff, and how the first 20 seconds promise it.
- Clip list: source URL, in and out times, length (20s or less), what the commentary adds.
- Shorts: 5 ideas, one idea each, 35 to 50 seconds, each ends on its payoff.
- Go-public list: the episode's time, and each Short's day and time, never two on one day.
- Standing notes: every memory entry tagged "standing note", copied in full.
- Open risks: rights questions, claims without a source yet.

## 2. Self-check

Check with tools, and say how you checked each line:

1. Runtime is inside the target.
2. First line and first frame match the brief.
3. Every standing note is met.
4. Narration is Kokoro am_onyx at speed 1.05 with no processing.
5. Audio: no clipping, voice sits above music, no silence over 2 seconds unless planned, about -14 LUFS.
6. Captions match the narration word for word.
7. Every clip is within its planned length, 20s or less, and carried by commentary.
8. Clips are roughly a quarter to a third of runtime.
9. The format differs from at least one of the last two episodes (check sagas.md).
10. Every factual claim about a real person has a source link in the description.
11. Branding matches the brand line.
12. Each Short ends on its payoff with no outro and has a distinct first frame.

Fix each miss and re-check that line. List anything you could not check.

## 3. Approval

Under the weekly routine's standing yes, a cut that passes the self-check is scheduled; report the brief, the self-check and the go-public list in the run report. Otherwise send Steven one message: preview link, the brief, the self-check (with any unchecked lines) and the go-public list, and ask for all notes in one reply, with timestamps.

## 4. Notes and recuts

1. Number the notes. Ask one question only if a note is unclear; otherwise start.
2. Change only the noted segments. Re-render. Re-run the self-check lines the change touches.
3. Reply with a change log: note number, what changed, timestamp.
4. Save any note that applies beyond this episode to memory as a standing note, with its reason and source. Update DAILY-RECIPE.md if the note changes the recipe, using the shared-file rule.
5. After a second recut, ask Steven whether the brief itself is wrong before a third.

## Anti-patterns

- Scheduling or showing a cut that has not passed the self-check.
- Rebuilding the whole episode for a note about one segment.
- Recutting after each note while more notes are still coming.
- Pasting long render logs into chat.
- Treating "approve the upload" as covering anything not on the go-public list.
