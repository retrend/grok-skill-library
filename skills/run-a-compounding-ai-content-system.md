# Run a compounding AI content system

## Steps
0. **Do the work first.** Every piece starts from a real problem, an artifact you built and a lesson. Ask yourself: what was hard to understand, what did I build to make it clearer, which constraint changed the design, and what would I do differently? Never outsource ideation to AI.
1. **Build the swipe file.** In [NOTES_VAULT] (e.g. Obsidian), create a swipe-file folder and clip full-text posts and articles into it with a web clipper. Add a one-line note on why each piece works, plus tags. Keep a `voice.md` file of your own writing that sounds like you. Point your drafting agent at both before it writes anything.
2. **Send out the scouts** (as routines):
   - **Outlier scanner** (daily): "Every morning, search X for posts and articles in [NICHES] from the last 24 hours. Compare each one's view count to the account's follower count. Send me the ten biggest outliers, with the link, the views, the follower count, and one line on why you think it worked."
   - **Reply analyst** (Mondays): pull replies to your posts from the last 30, 60 and 90 days, sort them into what people liked, disliked and asked for, and write a weekly ideas brief.
   - **Content strategist** (48 hours after each post): break down the post's style, format, topic and metrics, and write the analysis into the vault.
3. **Talk it, draft it, edit it.** Dictate the core argument (e.g. with Wispr Flow) so the raw material is in your natural voice. Then prompt: "I want to do an article about [TOPIC]. Refer to the swipe file for related articles, then brainstorm an outline." Have the agent draft from the outline, your voice file and the swipe file. Edit by hand: cut, fix claims and sharpen the opening.
4. **Make the visual earn its place.** Ask for a clean diagram of the idea. If it comes out bland, attach style reference images: "The graph was bland. Use these reference images for design style and visual direction and make it look a lot better."
5. **Publish the useful thing.** The article carries the value and the post is the hook that gets it opened. On X, quote-post your own post with a second piece of media and a slightly different take.
6. **Close the feedback loop** with two analyst agents. A voice analyst updates `voice.md` with word choices, sentence length and intro structures. A performance analyst writes what worked and what underperformed back into the vault.
7. **Let it compound.** Each weekly cycle starts from the updated vault, voice file and briefs.

## Not for
Fully automated, AI-originated content with no real experience behind it, or posting drafts without a human edit.
