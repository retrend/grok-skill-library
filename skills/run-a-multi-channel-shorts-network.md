# Steps

1. Treat multiple channels as a **network with jobs**, not income diversification. One channel is a video business; a network is a machine where formats, rivalry, and cross-traffic are deliberate.
2. **Sacrificial / burner channel:** Never test new formats on the channel that pays you. Run experiments on a burner for ~30 videos; only promote formats that clear onto the money channel. Format tests on the asset re-classify it and can crush the floor for weeks.
3. **Rival pair:** Two channels, same niche, opposite stances (e.g. guilty vs innocent), same editor/footage/template/operator. Comment sections on A become script fuel for B; platform treats conflict as engagement.
4. **Comment seeding:** Within ~60 seconds of upload, post the first comment from a second account — often the *wrong* take on purpose — to frame the thread and pull retention (people return to see corrections). Self-replies help hold top position.
5. **Language split:** Same script, dubbed; separate channels so feeds don’t cannibalize; each clears monetization thresholds in different ad markets.
6. **Cross-seed:** Shorts get one clickable link that must stay on-platform to your property — use the pinned comment as the door to the sibling/rival channel.
7. **Hygiene:** Brand accounts under one login pattern carefully; separate Google accounts for anything you sell; 2FA everywhere with current recovery email; editors get channel permissions never passwords; avoid logging many accounts from constantly rotating locations (that pattern flags).
8. **Monetization constraint (per source):** From February, each channel needs **10M Shorts views per rolling 90 days** to get paid at all — fewer, bigger, job-specific channels beat twelve hobby channels that earn nothing.

## Anti-patterns

- Testing formats on the paying channel
- Many weak channels that miss the rolling Shorts view floor
- Handing editors passwords instead of roles
- This is not a “grow one faceless channel” skill — it’s multi-channel network ops (and some tactics are adversarial/platform-gray)
