# Optimize About Us for AI search

Rewrite (or create) an About Us page with eight fixed sections so humans trust the brand and AI systems can cite accurate facts.

## Inputs

- `[COMPANY]`, `[CATEGORY]`, `[ICP]`
- Services / products and outcomes
- Competitors and quantified differentiators
- Founders, origin story, social links
- Process facts: channels, response times, who customers work with, turnaround, onboarding
- Key facts for the table (founded, HQ, pricing, contract terms, clients, volume metrics)
- FAQ questions buyers actually ask

## Steps

1. **Value prop (opening sentence)**  
   Lead with one clear line:  
   `[COMPANY] is a [CATEGORY] that [DOES XYZ] for [ICP].`

2. **What [COMPANY] does (H2)**  
   Under this H2, put each service / feature / product as an **H3**.  
   Write 2–3 sentences per item: what you do and what outcome it produces.

3. **What makes [COMPANY] different (H2)**  
   List about **5** core differentiators as H3s.  
   Make them specific and quantifiable. Call competitors by name.  
   Example pattern: `[COMPANY] offers month-to-month payment terms, whereas options like [COMPETITOR] have mandated 12-month contracts.`  
   Again: 2–3 sentences per differentiator.

4. **Who uses [COMPANY] (H2)**  
   Bullet exact ICP segments (not vague personas).  
   Example: `B2B SaaS marketing teams at 50 to 200 employees.`

5. **The team behind [COMPANY] (H2)**  
   Include founder names, short backstories, company origin, team composition, and links to socials (especially founder profiles).  
   About **2 sentences** per backstory / origin beat.

6. **How [COMPANY] works (H2)**  
   Cover communication channels, response times, who on the team customers work with, turnaround time, and onboarding process.

7. **Key facts (H2) — critical for AI search**  
   Use a crawlable HTML `<table>` or `<dl>` (definition list). Include rows for:

   | Row |
   | --- |
   | Company Name |
   | Type |
   | Founded |
   | Founder |
   | Headquarters |
   | Website |
   | Core Offering |
   | Pricing |
   | Contract Terms |
   | Services |
   | Communication |
   | Notable Clients |
   | Customers Served |
   | Projects Delivered |
   | Competitors |
   | Social |

8. **FAQ (H2)**  
   Heading: `Frequently asked questions`.  
   Each question is an **H3**. Answers stay **2–3 sentences**.

## Why this page matters (keep in mind while writing)

1. Helps train AI to talk about the brand accurately  
2. Strengthens E-E-A-T signals for the whole domain  
3. Makes the brand feel human when most content feels fake  

## Success check

- Opening line matches the `[COMPANY] is a [CATEGORY]…` pattern  
- All eight sections present with the stated heading structure  
- Differentiators name competitors and use numbers where possible  
- Key facts live in a real `<table>` or `<dl>`, not a screenshot or vague paragraph  
- FAQ answers stay short (2–3 sentences)

## Anti-patterns

- Vague “we’re passionate about…” copy with no ICP, no competitors, no numbers  
- Key facts only as an image (not crawlable)  
- Skipping team / process sections  
- Turning this into a long essay instead of scannable H2/H3 sections  
- Lead-magnet or sales-page structure that replaces About Us facts
