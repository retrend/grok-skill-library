# Steps

Run one copy of this checklist per release. Fill the header, set targets before you spend, and work phase by phase. Dates are relative to release day (T-0).

**Header**
- Release name:
- Release date:
- Current phase:

## Phase 1 — Operational setup and rights (T-8 to T-4 weeks)

**Distribution**
- [ ] Production and post-production finished
- [ ] Final master exported
- [ ] Final master submitted to distributor
- [ ] Release date scheduled about 8 weeks out (leaves room for editorial pitching)
- [ ] Metadata complete (titles, ISRC, credits, genre, explicit flag, artwork)
- [ ] Distributor review passed, then submit

**Rights and royalties**
- [ ] Registered with your performing-rights organisation (source used Buma Stemra, Netherlands)
- [ ] Registered with your neighbouring-rights / recording-rights body (source used Sena)
- [ ] Credits verified (writers, producers, featured artists, splits)

**Sync and licensing**
- [ ] Full version submitted to sync platforms
- [ ] Instrumental version submitted to sync platforms

**Digital infrastructure**
- [ ] Smart link created
- [ ] Linktree (or link-in-bio) updated
- [ ] Bandcamp, Audius, and SoundCloud uploads prepared (scheduled or ready)

**Audience conversion**
- [ ] Download gate created (source used Hypeddit) to trade a free download for follows or email
- [ ] Pre-save campaign prepared

**Targets and baselines (set now, review at T+4)**
- [ ] Week-1 streams target
- [ ] Spotify followers gained target
- [ ] Email subscribers gained target
- [ ] Discord members gained target
- [ ] Playlist placements target
- [ ] Revenue target
- [ ] Content pieces published target
- [ ] Ad budget per platform written down (Facebook/Instagram ads, Feature.fm, YouTube ads, Spotify Marquee/Showcase). No paid line runs without a budget.

## Phase 2 — Pre-release campaign (T-4 to T-1 weeks)

**Algorithm preparation**
- [ ] Shortlist the top 25 relevant curators, radio shows, and blogs (source used getheard.fm) and write them down
- [ ] Playlist pitch written
- [ ] Spotify for Artists editorial pitch submitted (must be before release day)
- [ ] Pre-save campaign launched

**Outreach**
- [ ] Premiere channels contacted
- [ ] Blogs contacted for a release-day feature
- [ ] Personalised emails sent to your fan list
- [ ] UGC (user-generated content) assets prepared: clips, sound, prompt for fans

**Narrative and positioning**
- [ ] Track story defined: how the track came about and how you made it
- [ ] Core emotion defined: the emotional reason you made the track
- [ ] Release caption written for SoundCloud, Audius, and similar
- [ ] Short release announcement written for message boards and communities

**Content**
- [ ] Track breakdown
- [ ] “Out now” video
- [ ] Emotional-story video
- [ ] Promo video sized for posting in groups
- [ ] Content concepts drafted (from your own reference doc or hook bank)
- [ ] All content rendered and ready
- [ ] Upload schedule set

## Phase 2.5 — Lead-time submissions (T-1 to T-0 weeks)

Everything a third party needs before release day:

- [ ] Radio submissions and radio pitching platforms
- [ ] Relevant YouTube channels pitched for a feature
- [ ] Blog feature submissions, with draft copy attached
- [ ] Track sent to promo pools
- [ ] Track sent to your DJ email list
- [ ] Industry outreach (managers, agencies) done

## Phase 3 — Release day (T-0)

**Own platforms (SoundCloud, Bandcamp, Audius)**
- [ ] Posted
- [ ] Monetisation switched on
- [ ] Native promotion on (paid only if budgeted)
- [ ] Music video posted
- [ ] Shorts posted

**Platform updates**
- [ ] Website updated
- [ ] Branding / banners updated
- [ ] Link-in-bio updated
- [ ] Every profile updated

**Announcement**
- [ ] Release announcement published
- [ ] Posts pinned on profiles

**Community activation**
- [ ] Fan email sent
- [ ] Discord announcement posted
- [ ] Facebook communities posted (follow each group’s rules)
- [ ] X post made
- [ ] Reddit posts made, value-first (see rules below)
- [ ] DMs sent to people who said they want to hear it
- [ ] Blog features live and shared

## Phase 4 — Post-release momentum (T-0 to T+2 weeks)

**Ongoing promo**
- [ ] SubmitHub follow-ups on anything not placed
- [ ] Groover follow-ups
- [ ] Repost-exchange campaign
- [ ] Feature.fm ads running (if budgeted)
- [ ] Facebook and Instagram ads running (budget approved)
- [ ] Independent curator outreach finished
- [ ] Reddit promo, value-first
- [ ] Other submission services you use (source listed “Lets Submit” and Triple Vision promo)
- [ ] Discord self-promo and ad channels
- [ ] Radio, YouTube channel, and blog submissions continue
- [ ] Spotify Marquee and Showcase live (if budgeted and eligible)
- [ ] Check your bookmarks for promo options you missed

**Algorithm support**
- [ ] Audience reminded to save the track
- [ ] Audience reminded to share the track

**Content waterfall**
- [ ] Studio breakdown video posted
- [ ] Emotional-story video posted
- [ ] UGC campaign started on all platforms
- [ ] Sample pack posted
- [ ] TikTok trend-format post

## Phase 5 — Community and long tail (T+2 to T+4 weeks)

**Extra promo**
- [ ] Spotify Discovery Mode (weigh the royalty trade-off)
- [ ] Influencer or creator outreach
- [ ] Instagram broadcast channel
- [ ] Instagram collab posts
- [ ] YouTube ads

**Community**
- [ ] Discord discussion thread
- [ ] Community engagement posts
- [ ] Audience feedback collected
- [ ] Remix competition, only if the release clearly took off
- [ ] Replies to fan comments

**Organic community outreach**
- [ ] Reddit engagement done value-first
- [ ] Discord engagement done in existing threads before posting your own
- [ ] At least some genuine contributions made before each promo post

## Value-first Reddit and Discord rules

1. Read each subreddit’s or server’s self-promo rules before posting. Many have a ratio rule or a dedicated promo thread.
2. Contribute before you promote: answer questions in threads, share a free sample pack, post behind-the-scenes or production tips.
3. Post the track where it fits the community, with context (story, how it was made), not a bare link.
4. Use designated self-promo threads and ad channels where they exist.
5. Reply to every comment on your posts.
6. Do not spam the same post across many communities at once.

## Agent notes

- An agent can draft pitches, captions, announcement posts, fan emails, and the curator shortlist, and track the checklist state. It must not post to communities, send emails or DMs, submit paid campaigns, or spend money without the artist’s explicit go-ahead per item.
- Platform names in brackets are the source’s picks. Swap in equivalents for your country or genre.

## Success check

- Release scheduled about 8 weeks out, with editorial pitch in before T-0.
- Rights and credits registered before release.
- Targets and ad budgets written before any spend.
- Every Reddit/Discord promo preceded by real contributions in that community.
- T+4 review filled in and fed into the next release.
